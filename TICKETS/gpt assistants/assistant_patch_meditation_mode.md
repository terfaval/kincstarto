# PATCH – Meditation Mode mező

## Új kötelező mező

"meditation_mode": "kontemplativ" | "imaginativ"

## Felismerési szabály

### kontemplativ
- kevés vizualizáció
- légzés, jelenlét, figyelemvezetés

### imaginativ
- erős képi világ
- jelenetek, terek, narratív belső utazás

## Ha nem egyértelmű

- kerüljön a bizonytalanságok közé
- kérjen megerősítést

## Kötelező

- minden JSON-ban szerepelnie kell
